# LemonClaw documentation

LemonClaw is a self-hosted AI digital employee agent with terminal, Feishu, and Webhook access to models, tools, memory, scheduling, and multi-agent workflows.

Start with [quick start](getting-started.md) to complete a terminal conversation, then see [deployment](deployment.md) for background services.
