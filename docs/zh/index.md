# LemonClaw 文档

LemonClaw 是可自行部署的 AI 数字员工 Agent，可通过终端、飞书和 Webhook 使用模型、工具、记忆、定时任务及多 Agent 工作流。

第一次使用请从[快速开始](getting-started.md)完成一次终端对话；部署后台服务再阅读[部署说明](deployment.md)。
