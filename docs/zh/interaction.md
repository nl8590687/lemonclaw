# 通知与人工确认

## 关键通知

主 Agent 通常给出最终答复；必要时会发送关键进展或阻碍通知。已完整交付结果时可避免重复答复；后台事件无需关注时可以静默完成。用户消息与定时任务不会仅因“无需关注”而省略回复。

## 回答人工确认

任务遇到关键选择或缺少资料时，Agent 可发起单选、多选或文本问题。

- 终端：单选输入 `1`，多选输入 `1,2`；其他答案使用 `0:实际答案`。多个文本题可用 `1:小明,2:28岁`。
- 飞书：使用卡片下拉框、文本框和确认/取消按钮。
- `/question`：在原入口重新查看/发送当前问题，不延长时限。
- `/cancel`：取消当前问题。
- `/clear`：清理当前会话，并使旧问题失效。

只能由原入口/发起用户回答。默认等待一小时，允许的时限为 20 分钟至 24 小时。超时或取消后不自动猜测答案；相关工作流保持暂停。等待状态可跨重启保留，离线时间也计入超时。

## 飞书配置

应用需要启用 `card.action.trigger` 卡片回传交互，使用已有长连接接收。没有配置回调时，可在原聊天用文字回答或取消；卡片丢失可用 `/question` 重发。完整后台配置截图待补充。

## 会话恢复

中断任务可在后续输入到达时从保存状态恢复。部分工具可能在恢复时再次执行，涉及外部写入的任务应确认幂等性。终端与飞书默认共享个人主会话，不应假设不同入口天然隔离。
