# 运维与备份

## 日志

前台运行时查看终端输出；Docker 后台运行时可使用 `docker logs --tail 100 lemonclaw`。分享日志前去除密钥、用户消息和敏感文件内容。

## 持久化范围

- `.lemonclaw/.env`：模型、通道和工具配置，包含密钥。
- `.lemonclaw/lemonclaw.db`：唯一数据库，保存会话、记忆及工作流等状态。
- `.lemonclaw/mcp.json`：MCP 配置，可能包含 token。
- `.lemonclaw/skills/`：自定义技能。
- 附件和工作文件：按实际目录单独保留，见[部署](deployment.md)。

## 升级前

记录当前代码提交或镜像标签；备份数据与配置，阅读目标版本的提交信息、PR 和 Release 说明。在非生产副本验证后再升级。
